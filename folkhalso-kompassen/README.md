# Folkhälsokompassen prototype

A Vite + React prototype for a cardiovascular disease risk simulation dashboard for Västerbotten.

## Open locally in VS Code

1. Unzip this folder.
2. Open the folder in VS Code.
3. Open the VS Code terminal and run:

```bash
npm install
npm run dev
```

4. Open the local URL shown in the terminal, usually:

```text
http://localhost:5173
```

## Notes

- No Tailwind setup is required; the prototype uses regular CSS in `src/styles.css`.
- The interactive municipality map is in `src/App.jsx` as inline SVG paths.
